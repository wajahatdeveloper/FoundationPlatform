Third-Party Notices
===================

This package embeds no third-party runtime libraries. Async code targets UnityEngine.Awaitable
(core engine); the previously embedded Cysharp UniTask has been removed.

-------------------------------------------------------------------------------
Unity packages
-------------------------------------------------------------------------------
This package depends on official Unity packages declared in package.json
(for example com.unity.inputsystem and com.unity.ugui). Those components are
governed by Unity's own terms.
