### New in this pass — mechanical "no optional parameters" cleanup
- **Info, verified safe** — The bulk of the diff (`EventBus.cs` +39, `Events.cs` +13, `EventBusUtilities.cs` +34, plus the small edits to the five window files) is a mechanical sweep removing C#-optional/default parameters and replacing them with explicit forwarding overloads, e.g. `Subscribe<T>(Action<T> callback, int priority, Identity channel)` (no more `= 0`/`= default`) plus new `Subscribe<T>(Action<T> callback, Identity channel)` and `Subscribe<T>(Action<T> callback)` overloads that forward to it (`EventBus.cs:928-936`); same pattern for `SubscribeWithToken`, `Unsubscribe`, `GetSubscriberCount`, `ConfigureMonitoring` (`EventBus.cs:1955-1956` — `ConfigureMonitoring(bool enabled)` forwards to the 6-arg version with the same defaults the old optional parameters used: `10, true, true, 75, false`), `GamePaused`/`GameResumed` constructors in `Events.cs` (new 1- and 2-arg constructors chain to the 3-arg one with the same former defaults, `"Manual"`/`true`), and the Editor navigation helpers in `EventBusUtilities.cs` (`NavigateToRuleExplorerByHandlerType`, `NavigateToSubscribersWindowByEventType`, etc.). This targets `docs/00-AgentGuide.md`'s "No optional parameters" rule. Verified non-breaking: grepped the whole HOMAM tree (not just this package) for call sites of `EventBus.ConfigureMonitoring(`, `new GamePaused(`/`new GameResumed(` (found in `Packages/com.aethernexus.gameenginecore/Runtime/Systems/Game/Session/GameSession.TimeControl.cs:77,102`, both using the full 3-arg form, still valid), and `EditorToolNavigation.NavigateToRuleExplorer(handlerType: ...)`-style named-arg calls — all existing call sites in the repo already match one of the new overloads exactly (all renamed call sites within this package's own Editor windows were updated in the same diff, e.g. `ActiveSubscriptionsWindow.cs`, `EventPublishHistoryWindow.cs`, `SubscriptionHistoryWindow.cs` now call `NavigateToRuleExplorerByHandlerType(handlerType)` instead of `NavigateToRuleExplorer(handlerType: handlerType)`). No behavior change, no regressions found.
